API Layers:
┌─────────────────────────────────────────────────────────────────────────────┐
│                              API Hierarchy                                  │
└─────────────────────────────────────────────────────────────────────────────┘

High-Level API:
├── buildVolumeFromSeries()     [Complete pipeline in one call]

Mid-Level APIs:
├── assembleVolume()            [DICOM → 3D Volume]
├── correctOrientation()        [Orientation correction]
├── resampleVolume()            [Isotropic resampling]
└── validateVolumeForML()       [Quality validation]

Low-Level APIs:
├── applyWindowPreset()         [CT windowing]
├── normalizeHU()               [Value scaling]
├── connectToOrthanc()          [PACS connection]
└── extractMetadata()           [DICOM processing]

Data Structures:
┌─────────────────────────────────────────────────────────────────────────────┐
│                            Data Flow                                        │
└─────────────────────────────────────────────────────────────────────────────┘

Input:  DICOM Directory → File Paths → DICOM Info → Sorted Metadata
Output: 3D Volume Array + Voxel Spacing + Processing Metadata

Volume: [rows × cols × slices] array
Spacing: [x, y, z] in mm
Metadata: Struct with processing details, timing, validation results
